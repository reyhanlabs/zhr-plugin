🚀 Quick Start

1️⃣ Login
Gunakan Google untuk login ke aplikasi. Hanya pengguna yang terdaftar yang dapat mengakses.
2️⃣ Dashboard
Lihat statistik real-time, quick actions, dan upcoming expiry di halaman utama.
3️⃣ Tambah/Kelola Data
Gunakan menu untuk tambah registrasi baru atau edit data yang sudah ada.
4️⃣ Export/Import
Kelola data dalam format CSV atau Excel untuk backup dan sharing.

📊 Dashboard - Halaman Utama

⚡ Quick Actions

Empat tombol pintas di bagian atas dashboard untuk akses cepat:

➕ Tambah Registrasi - Langsung ke form input data baru
👤 Kelola User - Buka modal untuk manajemen user (admin saja)
📥 Export CSV - Download semua data dalam format CSV
📤 Import Excel - Upload data dari file Excel/CSV (admin saja)

📈 Highlight Cards

Tiga kartu statistik penting menampilkan:

📊 Total Registrasi - Jumlah keseluruhan data yang terdaftar dalam sistem
✅ Status Aktif - Berapa banyak registrasi yang masih berlaku sampai sekarang
⏰ Akan Expired - Registrasi yang akan kadaluarsa dalam 30 hari ke depan

📦 Distribusi Paket

Breakdown visual dari setiap paket plugin yang digunakan:

Menampilkan total registrasi per paket: Starter, Professional, dan Enterprise. Update otomatis saat data berubah.

🔔 Upcoming Expiry

Fitur smart alert untuk registrasi yang akan expired:

⚠️ Menampilkan maksimal 5 registrasi paling urgent yang akan expired dalam 30 hari

Setiap kartu menunjukkan nama perusahaan, tanggal expired, dan sisa hari dalam format countdown. Klik untuk edit.

📋 Data Registrasi

Searching & Filtering

Di bagian atas tabel tersedia:

🔍 Search Box - Ketik untuk cari berdasarkan nama perusahaan, invoice, atau paket
Filter Status - Pilih "Aktif" atau "Kadaluarsa" untuk filter berdasarkan status

Status Badges

Setiap registrasi memiliki status badge dengan warna berbeda:

✅ Aktif
⏰ Akan Expired
❌ Kadaluarsa

Action Buttons

Setiap row memiliki 2 tombol action:

✏️ Edit - Buka form untuk mengedit data registrasi yang dipilih
🗑️ Hapus - Hapus data registrasi (confirm terlebih dahulu)

📝 Tambah/Edit Registrasi

Field-Field yang Harus Diisi

Nama Perusahaan *
Nama lengkap perusahaan customer
Invoice *
Nomor invoice atau reference number
Paket Plugin *
Pilih: Starter, Professional, atau Enterprise
Tipe Registrasi *
Pilih: Komersial, Internal, atau Trial
Tgl Registrasi *
Tanggal saat registrasi dilakukan
Tgl Aktif Hingga *
Tanggal registrasi akan kadaluarsa
Catatan
Keterangan tambahan atau notes penting (opsional)

Tips Penggunaan

💡 Tips Mengisi Form:

  • Field dengan * (bintang merah) harus diisi
  • Fokus pada input akan menampilkan highlight biru
  • Gunakan tombol "Reset" untuk membersihkan form
  • Klik "Simpan Data" setelah mengisi semua field

💰 Rekap Komisi & Laporan

Rekap Komisi

Menampilkan ringkasan komisi dari semua registrasi dalam bentuk tabel yang rapi. Gunakan tombol Cetak untuk mencetak laporan ke printer atau PDF.

Riwayat Update

Lihat log semua perubahan data dan aktivitas pengguna. Berguna untuk audit trail dan tracking perubahan historis.

Export/Import

📥 Export CSV - Download semua data dalam format CSV yang bisa dibuka di Excel
📤 Import Excel - Upload data dari file Excel/CSV (hanya untuk admin)

⚙️ Pengaturan & Fitur Lainnya

❓ FAQ - Pertanyaan Umum

Q: Bagaimana cara menghapus data?

A: Klik tombol "Hapus" di baris data, sistem akan meminta konfirmasi sebelum menghapus.

Q: Bagaimana cara export data?

A: Klik tombol "Export CSV" di quick actions atau menu Informasi Sistem untuk download data.

Q: Siapa yang bisa import data?

A: Hanya admin yang memiliki akses untuk import data dari Excel/CSV.

Q: Bagaimana jika lupa password?

A: Gunakan fitur "Forgot Password" di Google atau hubungi administrator sistem.

Q: Berapa lama data disimpan?

A: Data disimpan di Firebase cloud secara permanent sampai dihapus manual.

Q: Bisa backup data?

A: Ya, gunakan fitur "Export CSV" untuk membuat backup data secara berkala.
