🔑 Cara Login ke Sistem
  1. 1
    Buka Aplikasi
    Akses URL aplikasi melalui browser (Chrome atau Edge direkomendasikan). Anda akan melihat halaman login dengan tombol Google.
  2. 2
    Klik "Login dengan Google"
    Akan muncul popup login Google. Pilih akun Google yang sudah didaftarkan oleh Administrator ke dalam sistem whitelist.
  3. 3
    Verifikasi Otomatis
    Sistem akan memverifikasi apakah email Anda terdaftar. Jika ya, Anda langsung masuk ke Dashboard. Jika tidak, akan muncul pesan "Akun tidak terdaftar."
⛔ Akun ditolak? Hubungi Administrator untuk menambahkan email Anda ke daftar pengguna yang diizinkan.

🌙 Dark Mode & Tema Tampilan
  1. 1
    Via Tombol Topbar
    Klik tombol 🌙 di pojok kanan atas untuk toggle antara Light Mode dan Dark Mode.
  2. 2
    Via Pengaturan

⬇️ Export Data ke CSV
  1. 1
    Buka Daftar Registrasi
    Klik menu Daftar Registrasi di sidebar.
  2. 2
    Filter Data (opsional)
    Gunakan kotak pencarian atau filter status untuk mempersempit data yang ingin diekspor.
  3. 3
    Klik Tombol Export CSV
    Klik tombol Export CSV di toolbar. File akan otomatis diunduh dengan nama registrasi_plugin_[tanggal].csv.
💡 CSV yang diekspor mengandung kolom: No, Nama Perusahaan, Invoice, Paket Plugin, Tgl Registrasi, Aktif Hingga, Status, User Input, Informasi Registrasi, dan Catatan.
➕ Menambah Data Registrasi Baru
  1. 1
    Buka Form Input
    Klik menu Input Registrasi di sidebar, atau klik tombol + Tambah di topbar kanan atas.
  2. 2
    Isi Data Wajib
    Field bertanda * wajib diisi: Nama Perusahaan, Paket Plugin, Tanggal Registrasi, Aktif Hingga, dan Tipe Registrasi.
  3. 3
    Pilih Tipe Registrasi
    Pilih salah satu dari 4 tipe yang tersedia. Tipe ini menentukan apakah registrasi masuk ke rekap komisi atau tidak. Lihat tabel tipe di bawah.
  4. 4
    Isi Informasi Registrasi
    Lengkapi No. Invoice, ID Komputer / No. Serial / Kode Aktivasi di kolom Informasi Registrasi, dan Catatan bila diperlukan.
  5. 5
    Simpan Data
    Klik tombol 💾 Simpan Data. Data langsung tersimpan ke Firestore dan muncul di Daftar Registrasi secara real-time.
⚠️ Klik ↺ Reset untuk mengosongkan semua field jika ingin memulai input baru dari awal.
🏷️ Tipe Registrasi & Komisi

Setiap registrasi wajib memilih tipe. Tipe menentukan apakah data masuk ke menu Rekap Komisi atau tidak.

TipeKomisiKeterangan
🆕 Baru✓ AdaCustomer pertama kali mendaftar plugin.
🔄 Perpanjangan✓ AdaCustomer lama memperpanjang masa aktif plugin.
♻️ Re-aktivasi✗ TidakCustomer lama yang pernah expired lalu aktif kembali.
🔧 Perbaikan✗ TidakGanti ID komputer, serial, atau kode — bukan transaksi baru.
💡 Data lama yang diinput sebelum fitur ini tersedia akan tampil dengan badge "–". Edit data tersebut dan pilih tipe yang sesuai agar muncul di Rekap Komisi.
✏️ Mengedit Data Registrasi & Riwayat Perubahan
  1. 1
    Klik Tombol Edit (✏)
    Di Daftar Registrasi, klik tombol ✏ pada baris yang ingin diedit. Modal edit akan terbuka dengan data terisi otomatis. Di bawah judul modal tertera info terakhir diubah oleh siapa dan kapan.
  2. 2
    Ubah Data yang Diperlukan
    Semua field bisa diubah termasuk Tipe Registrasi. Sistem akan otomatis mendeteksi field mana saja yang berubah.
  3. 3
    Klik "💾 Simpan & Catat History"
    Sebelum data baru disimpan, sistem otomatis menyimpan snapshot data lama beserta daftar field yang berubah ke riwayat. Data lama tidak hilang — tersimpan sebagai history.
✅ Jika tidak ada perubahan sama sekali, sistem akan menampilkan pesan "Tidak ada perubahan data" dan tidak menyimpan history kosong.

Melihat Riwayat Perubahan:

  1. 1
    Klik Tombol 🕐
    Setiap baris di Daftar Registrasi memiliki tombol 🕐 di kolom Aksi. Klik untuk membuka riwayat perubahan data tersebut.
  2. 2
    Baca Timeline Perubahan
    Setiap entri riwayat menampilkan: tanggal & jam perubahan, siapa yang mengubah, dan untuk setiap field yang berubah — nilai sebelum vs nilai sesudah.
🔒 Catatan Firestore Rules: Fitur riwayat perubahan membutuhkan izin akses sub-koleksi updateHistory. Pastikan Firestore Security Rules sudah mengizinkan akses ke match /registrasi/{id}/updateHistory/{h}.

🗑️ Menghapus Data Registrasi
  1. 1
    Klik Tombol Hapus (🗑)
    Di Daftar Registrasi, klik tombol 🗑 pada baris data yang ingin dihapus.
  2. 2
    Konfirmasi Penghapusan
    Dialog konfirmasi akan muncul menampilkan nama perusahaan. Klik Ya, Hapus untuk melanjutkan, atau Batal untuk membatalkan.
🚨 Perhatian! Penghapusan data bersifat permanen dan tidak dapat dibatalkan. Riwayat perubahan (sub-koleksi updateHistory) juga ikut terhapus.

  2. 2

💰 Rekap Komisi

Menu 💰 Rekap Komisi menampilkan khusus data yang memiliki komisi — yaitu tipe 🆕 Baru dan 🔄 Perpanjangan. Data tipe Re-aktivasi dan Perbaikan tidak akan muncul di sini.

  1. 1
    Buka Menu Rekap Komisi
    Klik menu 💰 Rekap Komisi di sidebar. Halaman akan langsung menampilkan semua data Baru + Perpanjangan.
  2. 2
    Filter Periode
    Gunakan dropdown Bulan dan Tahun untuk memfilter per periode. Dropdown Tipe untuk melihat Baru atau Perpanjangan saja.
  3. 3
    Export atau Cetak
    Klik ⬇ Export CSV untuk mengunduh file spreadsheet bernama rekap_komisi_[tahun]-[bulan].csv, atau klik 🖨 Cetak untuk membuka halaman cetak yang sudah diformat rapi.
⚠️ Pastikan semua data sudah diisi tipe registrasinya dengan benar. Data tanpa tipe (badge "–") tidak akan muncul di Rekap Komisi meskipun seharusnya ada komisi.
👥 Manajemen User & Role Admin Only

Sistem menggunakan 2 level role:

Admin
Akses penuh: dapat menambah/menghapus user, import data Excel, backup/restore, dan semua fitur CRUD.
User
Akses terbatas: dapat input, edit, lihat, dan filter data. Tidak bisa import Excel atau mengelola user lain.

Cara Menambah User Baru:

  1. 1
    Buka Pengaturan
    Masuk ke menu ⚙️ Pengaturan → Manajemen User.
  2. 2
    Isi Form Tambah User
    Masukkan Nama, Email Google, dan pilih Role (Admin/User).
  3. 3
    Klik Tambah User
    User langsung bisa login menggunakan akun Google dengan email tersebut.
🚨 Hanya Admin yang dapat menambah atau menghapus user. Admin juga tidak dapat menghapus dirinya sendiri dari sistem.
💾 Backup & Restore Data Admin Only

Backup Data:

  1. 1
    Pengaturan → Backup & Restore
    Klik tombol ⬇ Backup JSON. Semua data dari Firestore akan diunduh sebagai file backup_plugin_[tanggal].json.

Restore Data:

  1. 1
    Klik Restore JSON
    Klik tombol ⬆ Restore JSON, lalu pilih file backup .json yang sudah ada.
  2. 2
    Konfirmasi & Proses
    Sistem akan menampilkan progress bar selama proses restore. Restore bersifat additive — data lama tidak dihapus, data dari file JSON ditambahkan.
⚠️ Restore tidak menghapus data lama. Jika ingin mengganti seluruh data, hapus data di Firestore Console terlebih dahulu sebelum restore.
🚀 Import Data Excel (First-Time Setup) Admin Only
🚨 Lakukan hanya sekali! Fitur ini untuk migrasi data awal dari Excel ke Firestore. Pastikan Firestore masih kosong sebelum menjalankan import.
  1. 1
    Cek Firestore
    Pastikan collection registrasi di Firestore Console masih kosong atau memang ingin ditambahkan data.
  2. 2
    Buka Pengaturan → Import Data Excel
    Klik tombol 🚀 Import Data ke Firestore. Progress bar akan menampilkan proses batch per 400 record.
❓ Pertanyaan yang Sering Diajukan
Q: Mengapa saya tidak bisa login?
A: Kemungkinan email Google Anda belum terdaftar di whitelist sistem. Hubungi Administrator untuk meminta akses. Pastikan Anda menggunakan akun Google yang benar.
Q: Data saya tidak muncul / refresh sangat lama?
A: Periksa indikator koneksi di topbar. Jika menunjukkan "Offline" 🔴, berarti koneksi ke Firebase terputus. Coba refresh browser atau periksa koneksi internet Anda.
Q: Apakah data aman jika browser ditutup?
A: Ya. Semua data tersimpan di Firebase Firestore (cloud), bukan di browser. Data tidak akan hilang saat browser ditutup atau komputer dimatikan.
Q: Bagaimana cara memilih beberapa paket plugin sekaligus?
A: Di form Input Registrasi, klik pada dropdown Paket Plugin lalu klik setiap paket yang ingin dipilih. Setiap paket yang dipilih akan muncul sebagai tag biru. Klik tanda ✕ pada tag untuk membatalkan pilihan.
Q: Apa perbedaan tipe Re-aktivasi dan Perpanjangan?
A: Perpanjangan dilakukan sebelum atau saat masa aktif berakhir — plugin masih aktif, customer memperpanjang. Re-aktivasi dilakukan setelah plugin sudah expired — customer mengaktifkan kembali setelah ada jeda tidak aktif. Perpanjangan ada komisi, Re-aktivasi tidak ada komisi.
Q: Data lama saya tidak muncul di Rekap Komisi, bagaimana?
A: Data yang diinput sebelum fitur Tipe Registrasi tersedia tidak memiliki nilai tipe, sehingga tidak masuk rekap komisi. Solusinya: buka Daftar Registrasi, klik tombol ✏ pada data tersebut, pilih Tipe Registrasi yang sesuai, lalu simpan.
Q: Muncul error "Missing or insufficient permissions" saat membuka riwayat 🕐?
A: Firestore Security Rules belum mengizinkan akses sub-koleksi updateHistory. Masuk ke Firebase Console → Firestore → Rules, dan tambahkan rule: match /registrasi/{id}/updateHistory/{h} { allow read, write: if request.auth != null; }
Q: Apakah riwayat perubahan ikut terhapus jika data dihapus?
A: Ya. Saat data registrasi dihapus dari Firestore, sub-koleksi updateHistory yang ada di dalamnya juga terhapus bersama. Lakukan backup terlebih dahulu jika perlu menyimpan riwayat tersebut.
Q: Bisakah User biasa menghapus data?
A: Ya, User biasa dapat menghapus data registrasi. Namun hanya Admin yang dapat mengelola user lain dan melakukan import/export massal.
Q: Apa yang terjadi saat restore, apakah data lama terhapus?
A: Tidak. Restore bersifat additive (menambahkan). Data dari file JSON akan ditambahkan ke Firestore tanpa menghapus data yang sudah ada. Jika ada Firestore ID yang sama, data akan di-merge.
📞 Kontak & Dukungan

Jika menemukan kendala yang tidak tercantum di panduan ini, silakan hubungi Administrator sistem atau tim teknis yang bertanggung jawab atas aplikasi ini.

✅ Tips: Selalu lakukan backup data secara rutin (minimal seminggu sekali) untuk menghindari kehilangan data akibat hal yang tidak terduga.
